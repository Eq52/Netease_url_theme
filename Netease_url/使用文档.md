# 网易云音乐工具箱 - 使用文档

## 项目简介

本项目是 Aural 音乐应用的完整服务端文档。Aural 是基于 [Suxiaoqinx/Netease_url](https://github.com/Suxiaoqinx/Netease_url) 二次开发的音乐体验应用，前端使用 Next.js 16 全新重写，采用黑金沉浸式主题设计。后端基于 Flask，提供网易云音乐相关的 API 服务，支持歌曲搜索、单曲解析、歌单解析、专辑解析和音乐下载等功能，支持多种音质选择，包括无损、Hi-Res、杜比全景声等高品质音频格式。

> 本文档主要描述后端 API 服务的使用方式。前端 Aural 主题的使用请直接通过浏览器界面操作。

## 功能特性

### 核心功能
- **歌曲搜索**：支持关键词搜索网易云音乐库中的歌曲
- **单曲解析**：解析单首歌曲的详细信息和下载链接
- **歌单解析**：批量解析歌单中的所有歌曲
- **专辑解析**：批量解析专辑中的所有歌曲
- **音乐下载**：支持多种音质的音乐文件下载

### 音质支持
| 音质 | 参数值 | 说明 |
|------|--------|------|
| 标准音质 | `standard` | 128kbps，免费可用 |
| 极高音质 | `exhigh` | 320kbps，需要黑胶 VIP |
| 无损音质 | `lossless` | FLAC 格式，需要黑胶 VIP |
| Hi-Res 音质 | `hires` | 24bit/96kHz，需要黑胶 VIP |
| 高清环绕声 | `jyeffect` | 需要黑胶 VIP |
| 沉浸环绕声 | `sky` | 需要黑胶 SVIP |
| 超清母带 | `jymaster` | 需要黑胶 SVIP |
| 杜比全景声 | `dolby` | Dolby Atmos，需要黑胶 SVIP |

### 使用方式
- **Web 界面**：Aural 前端提供直观的网页操作界面，支持搜索、播放、下载一体化操作
- **API 接口**：完整的 RESTful API，可用于二次开发
- **批量处理**：支持歌单和专辑的批量解析

## 快速开始

### 环境要求
- Python 3.7+
- 网易云音乐黑胶会员账号（用于获取高音质资源）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/Eq52/Netease_url_theme.git
   cd Netease_url_theme
   ```

2. **安装依赖**
   ```bash
   cd Netease_url
   pip install -r requirements.txt
   ```

3. **配置 Cookie**

   在 `cookie.txt` 文件中填入黑胶会员账号的 Cookie：

   ```
   MUSIC_U=你的MUSIC_U值;os=pc;appver=8.9.70;
   ```

   > **获取 Cookie 方法**：
   > 1. 登录网易云音乐网页版 (music.163.com)
   > 2. 按 F12 打开开发者工具
   > 3. 在 Network 标签页找到任意请求
   > 4. 复制请求头中的 Cookie 值

4. **启动服务**
   ```bash
   python main.py
   ```

5. **访问界面**

   打开浏览器访问：`http://localhost:5000`

   > 如需使用 Aural 前端界面，请先按照 README 中的说明构建 Theme 目录并部署到 templates/。

### 使用前端（Aural）

Aural 是全新设计的黑金主题前端，提供沉浸式音乐体验：

1. **构建前端**
   ```bash
   cd Theme
   npm install
   npm run build
   ```

2. **部署到后端**
   ```bash
   cp -r out/* ../Netease_url/templates/
   ```

3. **启动后端后访问** `http://localhost:5000`

前端功能包括：歌曲搜索、在线播放、实时歌词、音质选择、歌单/专辑浏览、行内下载等。

## 使用指南

### Web 界面使用（Aural 前端）

Aural 前端提供以下核心页面，通过左侧导航栏（桌面）或底部 Tab Bar（移动端）切换：

#### 歌曲搜索
1. 点击左侧「搜索」导航项
2. 在搜索框中输入关键词（歌曲名、歌手名等）
3. 点击搜索按钮或回车
4. 浏览搜索结果网格卡片
5. 点击任意歌曲卡片即可播放，或点击下载按钮直接下载

#### 歌单浏览
1. 点击左侧「歌单」导航项
2. 输入歌单 ID 或歌单链接
   - 支持格式：`1234567890` 或 `https://music.163.com/playlist?id=1234567890`
3. 查看歌单封面、描述和完整曲目列表
4. 点击任意歌曲即可播放

#### 专辑浏览
1. 点击左侧「专辑」导航项
2. 输入专辑 ID 或专辑链接
   - 支持格式：`1234567890` 或 `https://music.163.com/album?id=1234567890`
3. 查看专辑信息、发行时间和曲目列表
4. 点击任意歌曲即可播放

#### 设置
1. 点击左侧「设置」导航项
2. 可配置：
   - **默认音质**：选择播放时的默认音质等级
   - **Cookie 管理**：配置和管理网易云音乐账号 Cookie
   - **下载设置**：选择下载音质
   - **播放设置**：自动播放、歌词显示等
   - **关于**：查看版本信息和项目信息

### 播放器操作
- **MiniPlayer**：页面底部的迷你播放器，显示当前歌曲信息，支持播放/暂停/上下首切换
- **FullPlayer**：点击 MiniPlayer 或封面可展开全屏播放器，包含模糊背景、大封面、歌词滚动等

### 链接格式支持

项目支持多种网易云音乐链接格式：

- **歌曲链接**：`https://music.163.com/song?id=123456`
- **歌单链接**：`https://music.163.com/playlist?id=123456`
- **专辑链接**：`https://music.163.com/album?id=123456`
- **短链接**：`https://163cn.tv/xxxxxx`（自动跳转解析）
- **直接 ID**：`123456`

## API 接口文档

### 基础信息
- **服务地址**：`http://localhost:5000`
- **请求方式**：POST（部分接口支持 GET）
- **响应格式**：JSON
- **CORS**：默认允许所有来源

```json

  "success": true,

  "data": { }
}
```

## Docker 部署

### 使用 Docker Compose

1. **修改配置**（可选）

   编辑 `docker-compose.yml` 文件修改端口：
   ```yaml
   ports:
     - "8080:5000"  # 将服务映射到 8080 端口
   ```

2. **启动服务**
   ```bash
   docker-compose up -d
   ```

3. **查看日志**
   ```bash
   docker-compose logs -f
   ```

4. **停止服务**
   ```bash
   docker-compose down
   ```

### 使用 Dockerfile

```bash
# 构建镜像
docker build -t aural-music .

# 运行容器
docker run -d -p 5000:5000 -v $(pwd)/downloads:/app/downloads aural-music
```

## 故障排除

### 常见问题

#### 1. Cookie 无效
**问题**：提示 Cookie 无效或过期，无法获取高音质资源

**解决方案**：
- 确认使用的是黑胶会员账号
- 重新获取 Cookie 并更新 `cookie.txt`
- 检查 Cookie 格式是否正确
- 在 Aural 前端的「设置 → Cookie 管理」中检查状态

#### 2. 无法下载高音质
**问题**：只能下载标准音质，高音质提示失败

**解决方案**：
- 确认账号是黑胶会员（VIP/SVIP）
- 检查 Cookie 是否有效
- 确认歌曲本身支持对应音质
- SVIP 音质（sky, jymaster, dolby）需要黑胶 SVIP 账号

#### 3. 服务启动失败
**问题**：运行 `python main.py` 报错

**解决方案**：
- 检查 Python 版本（需要 3.7+）
- 安装所有依赖：`pip install -r requirements.txt`
- 检查端口 5000 是否被占用

#### 4. 前端页面空白
**问题**：访问页面显示空白或 404

**解决方案**：
- 确认已执行 `npm run build` 构建前端
- 确认 `Theme/out/` 内容已正确复制到 `Netease_url/templates/`
- 检查 `templates/index.html` 文件是否存在

#### 5. 下载文件损坏
**问题**：下载的音频文件无法播放

**解决方案**：
- 检查网络连接是否稳定
- 重新下载文件
- 尝试其他音质选项

## 项目结构

```

├── Dockerfile           # Docker 构建文件
├── docker-compose.yml   # Docker Compose 配置
├── build.bat            # Windows 打包脚本
├── entrypoint.sh        # Docker 入口脚本
└── 使用文档.md           # 本文档

Theme/                   # Next.js 前端源码（Aural 黑金主题）
├── src/
│   ├── app/             # 页面入口 + 全局样式
│   ├── components/      # React 组件

```

### 技术栈

**后端**：
- Flask (Python) — Web 服务框架
- mutagen — 音频元数据处理
- aiohttp + requests — HTTP 客户端

**前端（Aural）**：
- Next.js 16 — React 框架
- TypeScript — 类型安全
- Tailwind CSS 4 — 原子化 CSS
- shadcn/ui (Radix UI) — UI 组件库
- Framer Motion — 动画库
- Zustand — 状态管理
- APlayer — 音频播放器

**部署**：
- Docker / Docker Compose — 容器化部署
- PyInstaller — 可执行文件打包（Windows）
